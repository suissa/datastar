Accordion

A composable, accessible disclosure component inspired by the Radix UI Accordion API, implemented as native Web Components. No React dependency.

Single

One section at a time. The open section can be collapsed.

How do I install it?

Load accordion.css and accordion.js from your project, then compose the custom elements in your HTML.

 Does it work with Datastar?

Yes. It is framework-independent and can sit beside Datastar attributes and server-rendered HTML.

 What about accessibility?

Triggers expose expanded state and panel relationships, support keyboard navigation, and retain visible focus indicators.
value: installation

Multiple

Open any number of sections. Try opening all three.

Value change events

The root emits a bubbling value-change event. Read the selected value from event.detail.value.

 Custom styling

Override the CSS custom properties --ds-accordion-accent, --ds-accordion-border, and --ds-accordion-foreground.
